This project rewrites the Python client and sample bot in JavaScript for Node.js.
Some API interfaces and validation behavior were originally adapted from instagram-bot-api by Sheikh Tamim:
https://github.com/sheikhtamimlover/instagram-bot-api
Reference revision: 9782757c0496bfecd81a9bd85c90e1e3d7acad12 (1.0.1).
Its MIT license and copyright notice are included below.
Version 3 removes the Android transport and password/bearer session implementation.

The Instagram web Iris bootstrap, messaging and Mercury photo-upload behavior were cross-checked against
Aerogram 0.2.1 and then verified against Instagram's web service:
https://github.com/charindithjaindu/aerogram
Reference revision: 2c2a589b2dbe8717d964c86262de2bbf0dafa5a4.
The receiving parser, handler/filter semantics, voice/video upload, history and CDN
download behavior also use this revision as a reference. These additions are tested
offline; the SDK does not implement Aerogram's DGW transport.
Its MIT notice is included below. The MQTT.js compatibility
handling for Instagram's PUBACK frame was established by live connection tests.
